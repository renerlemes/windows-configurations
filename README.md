# SoundSwitch

O **SoundSwitch** gerencia dispositivos de reprodução e gravação pelo ícone da bandeja do sistema.

Configure uma vez e use pelo ícone na bandeja. Clique com o botão direito no ícone e escolha **Configurações**.

## Requisitos

- Windows 10 ou mais recente (x64)

## Reprodução

Marque os dispositivos de reprodução pelos quais deseja alternar e, se quiser, altere o atalho de teclado.

O atalho padrão é `Ctrl` + `F1`. Também é possível clicar com o botão esquerdo no ícone da bandeja e escolher o dispositivo.

![Reprodução](Docs/Recursos/1%20-%20Reprodução.png)

## Gravação

Marque os dispositivos de gravação pelos quais deseja alternar e, se quiser, altere o atalho de teclado.

O atalho padrão é `Ctrl` + `F2`. Também é possível clicar com o botão esquerdo no ícone da bandeja e escolher o dispositivo.

![Gravação](Docs/Recursos/2%20-%20Gravação.png)

## Configurações

**Geral**

- **Iniciar com o Windows** — abre o aplicativo automaticamente no login.

**Áudio**

- **Ao bloquear o computador, ativar o mudo** — o volume é silenciado ao bloquear a sessão e restaurado ao desbloquear.

**Notificações**

- **Mostrar notificação ao alterar um dispositivo** — uma notificação do Windows aparece ao trocar o dispositivo padrão.

**Versão**

Exibe a versão instalada e, se houver atualização, a versão disponível, o botão **Atualizar** e o progresso do download.
